# RFC 8439 test vectors

Source: https://www.rfc-editor.org/rfc/rfc8439 (June 2018).

These JSON files transcribe the published hexadecimal inputs and expected outputs.
No expected output was generated by the implementation under test.
All byte fields are hexadecimal; counter is a decimal initial block counter.
The id field identifies the RFC section and vector number, where applicable.

- chacha20.json: section 2.3.2 and appendices A.1, A.2, A.4 (12 cases).
  A.4 checks the first 32 bytes of block zero used as the Poly1305 one-time key.
- poly1305.json: section 2.5.2 and appendix A.3 (12 cases, including reduction edges).
- chacha20-poly1305-aead.json: section 2.8.2 and appendix A.5 (2 cases).
  Section 2.8.2's nonce concatenates the fixed common part and IV, in that order.
